# Boris Kirov Photography

Personal photography portfolio (OS-style shell).

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

- Stills / projects registries: `lib/stills.js`, `lib/projects.js`
- Project info markdown: `content/projects/{slug}.md`
- Images: `public/`
